# Source dossiers

Pass 1 is a provenance-and-credit pass. Each source gets its own directory before any synthesis is attempted.

## Mirroring policy used in this pass

None of the eight sources above is mirrored here. The four books are publisher-controlled works. The four shorter PDFs are legitimately available from author or university pages, but no explicit redistribution license was found in the PDFs during this pass. Publicly readable is not the same thing as permission to republish, so the repository links to their legitimate hosts instead.

If a later source carries an explicit permissive license or is clearly public domain, a local copy may be added together with the exact license/provenance record.
